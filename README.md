# xime-pclayout_MimiPc
## 仿PC快捷操作布局

### 经典PC端快捷操作复刻（上滑）
- `A` 全选
- `Z` 撤回
- `B` 回车
- `N` 重复上次操作
- `X` 剪切
- `C` 复制
- `V` 粘贴

## 中英键盘说明
- **空格**：语音面板改居中缩小，左右各加光标控制
- **逗号与句号合并**：单击逗号，上滑句号
- **位置**：逗号句号放左边，中英切换放右边
- **英标符**：中英文输入 `QWERPD` 上滑符号均为英标符
- **中文状态**：
  - 上下滑 `P` 对应运算符 `+` `-`
  - 上滑（留空处）对应运算符 `=`
- **中英状态**：上下滑 `M` 分别对应各自中英符 `!` `?`
- **英文状态**：适配常用命令符

## 数字键盘说明
- 将数字面板改为二级页面，绕过并屏蔽掉二级符号
- 左边处 `+` `-` `*` `/` 外多加 `@`
- 将空格键居中以适应多数人习惯
- 符号与表情一起放在右边
